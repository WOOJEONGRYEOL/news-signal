# 뉴스 시그널 (News Signal)

**공유 주소: https://woojeongryeol.github.io/news-signal/** (매시 0분·30분에 갱신)

뉴스룸용 실시간 관심사 보드. 포털 실시간 검색어(구글 트렌드·네이트·줌), 언론 발행량(네이버 섹션·연합뉴스·구글 뉴스 피드), 실제 소비(네이버 언론사별 많이 본 기사)를 한 화면에 모아 **카테고리별 Top 10 키워드**를 보여주고, 키워드를 누르면 **관련 기사 목록**과 **시간대별 흐름**이 나옵니다. 과거 시점도 골라서 볼 수 있습니다.

- 파이썬 표준 라이브러리만 씁니다. 설치할 패키지가 없고, API 키도 필요 없고, 비용도 0원입니다.
- 브라우저 화면(`site/index.html`)은 정적 파일이라 그대로 GitHub Pages나 사내 웹서버에 올릴 수 있습니다.

## 바로 쓰기

```bash
cd "/Users/woo/News Signal"
python3 -m newssignal doctor      # 출처 8곳 연결 점검
python3 -m newssignal collect     # 지금 한 번 수집 (약 30초)
python3 -m newssignal serve       # http://127.0.0.1:8770/ 에서 보기
```

`python3`는 Homebrew의 3.11 이상이어야 합니다(macOS 기본 `/usr/bin/python3`는 3.9라 안내 문구와 함께 멈춥니다).

## 자동 수집과 공유 (2026-09-12 등록 완료)

이 맥에 LaunchAgent `com.woo.newssignal`이 등록되어 **매시 0분과 30분에** `scripts/run_auto.sh`가 돕니다: 수집 → `site/data` 변경분 커밋 → GitHub 푸시 → GitHub Actions(`.github/workflows/pages.yml`)가 `site/`를 Pages에 배포. 로그는 `logs/collect.log`.

```bash
launchctl list | grep com.woo.newssignal        # 상태 (두 번째 칸이 마지막 종료 코드, 0이면 정상)
bash scripts/install_launchagent.sh              # 재등록 (스크립트나 간격을 바꿨을 때)
launchctl bootout gui/$(id -u)/com.woo.newssignal   # 해제
python3 -m newssignal loop --every 30            # LaunchAgent 대신 터미널에서 반복하고 싶을 때
```

맥이 잠자거나 로그아웃돼 있으면 그 시간대는 건너뛰고, 깨어나면 밀린 회차를 한 번으로 합쳐 돕니다.

### 부하와 무료 한도

- 출처 사이트: 수집 1회에 요청 약 45번(구글 트렌드 17, 네이버 7, 연합뉴스 11, 구글 뉴스 피드 7, 네이트·줌 2)에 구글 뉴스 검색 최대 25번이 더해집니다. 30분 간격이면 하루 2,000~3,000번 수준이라 차단·과부하 걱정은 없습니다. 10분 간격까지는 무난하고, 그보다 잦게 돌리려면 `news_search_limit`를 줄이는 게 좋습니다.
- GitHub: 공개 저장소라 Actions 실행 시간은 무제한이고, 배포 1회는 20초 안팎입니다. Pages는 월 100GB 전송이 소프트 한도인데 최신 데이터 파일은 gzip으로 160KB 정도라, 화면 수십 개가 하루 종일 켜져 있어도 여유가 큽니다.
- 브라우저: 화면은 1분마다 1KB짜리 `manifest.json`만 다시 읽어 새 수집이 있는지 확인하고, 새 수집이 있을 때만 데이터 파일을 받습니다. 출처 사이트에는 아무 요청도 보내지 않습니다. 저장소: https://github.com/WOOJEONGRYEOL/news-signal (Pages를 무료로 쓰려고 공개 저장소이며, 올라가는 건 공개 뉴스 데이터뿐입니다. `config.toml`·SQLite·로그는 올라가지 않습니다).

수집이 쌓일수록 좋아집니다. **급상승** 신호는 지난 7일 평균과 비교하므로 하루쯤 지나야 의미가 생기고, 키워드별 **흐름 곡선**도 수집 횟수만큼 점이 찍힙니다.

화면은 유리처럼 비치는 패널(반투명·블러) 위주의 밝은 테마이고, 시스템이 다크 모드면 어두운 유리로 바뀝니다. 휴대폰 폭(700px 이하)에서는 1열로 재배치되고 신호 막대 열은 숨겨지며, 관계망·연관어 고리는 세로형 캔버스로 다시 배치됩니다. 터치 기기에서는 마우스 올리기 대신 누르기(탭=고정, 빈 곳 탭=해제)로 동작하고 안내 문구도 그에 맞게 바뀝니다. 특정 화면은 주소로 공유할 수 있습니다: `#mode=story|keyword|map&cat=정치&kw=…&story=…&pin=…`

## 화면 구성

| 영역 | 내용 |
|---|---|
| 스토리 Top 10 (기본 화면) | 같은 사건을 다룬 기사 묶음 단위 순위. 한 사건이 여러 국면으로 갈라져 순위를 뒤덮지 않도록 **이슈 단위로 접어** 한 줄만 차지한다('국면 18' 표시, 상세에서 다른 국면을 눌러 볼 수 있음. 국면 목록은 4줄까지만 펼쳐 두고 나머지는 '더 보기'로 접어, 아래 흐름 그래프 위치가 분야마다 들쭉날쭉해지지 않게 함). 대표 헤드라인 + 공통 키워드, 기사 수, 많이 본 기사에 올린 언론사 수, 검색 출처. 누르면 한 문장 설명·흐름 곡선(24·48·72시간)·묶인 기사(많이 본 기사 먼저). 키워드 칩을 누르면 그 말이 든 기사만 남김 |
| 키워드 Top 10 | 단어 단위 순위(카테고리별). 누르면 **연관어 고리**가 펼쳐지고, 연관어를 누르면 그 조합의 기사만 남기며 한 단계씩 파고듦(경로 표시, 더블클릭하면 그 키워드로 이동) |
| 관계망 | 주요 키워드만 워드클라우드처럼 펼쳐 둔 화면. 점수가 높을수록 가운데에 놓이고 글자가 **차지하는 면적**이 점수에 비례함(긴 말은 그만큼 글자 크기를 줄여 자리 크기로 비교되게, 전체 면적은 화면의 42% 이내). 색은 카테고리, 같은 분야 말은 같은 방향에 모임. 호버로 펼쳐질 때도 카테고리 색을 유지하고 배경·연결선만 그 색 계열로 표시. 글자에 마우스를 올리면 그 말이 화면 중앙으로 이동하며 커지고, 함께 다뤄진 연관어들이 읽기 좋은 크기로 둘레에 고리 모양으로 펼쳐지며(클라우드에 없던 말 포함) 선으로 이어지고, 나머지는 바깥으로 물러나 흐려짐. 다른 키워드에 올리면 그쪽으로 옮겨 가고, 커서가 관계망 영역을 벗어나면 제자리로 돌아오는 애니메이션(글자만 벗어나는 것으로는 되돌리지 않음). 누르면 고정, 더블클릭하면 키워드 화면으로, 휠로 확대·끌어서 이동. 주소에 `noanim`을 붙이면 애니메이션 없이 최종 상태만 그림(스크린샷 검증용) |
| 포털 원본 | 구글 트렌드 전국 급상승, 네이트 실시간 이슈, 줌 AI 이슈트렌드, 네이버 많이 본 기사(우리 회사 Top 5 / 언론사별 1위) |
| 지역별 관심사 | 실제 시·도 경계 지도(Natural Earth 자료를 `scripts/build_krmap.py`로 단순화한 `site/kr-map.js`). 그 지역에서만 뜨는 검색어가 많을수록 진하게 칠해짐. 평소에는 4.5초마다 권역이 차례로 도드라지며 오른쪽에 그 권역의 급상승 검색어 순위가 위에서 아래로 펼쳐지고(자동 순환, 진행 막대 표시), 마우스를 올리면 멈추고 그 권역을 보여 주며, 누르면 고정(`#region=KR-45`처럼 공유 가능), 빈 곳을 누르면 순환 재개. '전국'은 전국 목록에도 있는 검색어, '이 지역만·지역 n곳'은 일부 시·도에서만 뜨는 검색어 |
| 화면 구조 | 위쪽 큰 토글(스토리·키워드·관계망)이 상위 화면이고, 그 아래 들여쓴 '분야' 줄(전체·정치·…)이 하위 필터임 |
| 시점 선택 | 상단에서 날짜·시각을 고르면 그 시점의 순위·기사·포털 원본으로 되돌아감. '지금'을 누르면 실시간 |

## 점수 (설정값이며 바꿀 수 있음)

**스토리 점수** — 같은 사건을 다룬 기사 묶음에 매기는 점수. `[story_weights]`

| 신호 | 뜻 | 기본 가중치 |
|---|---|---|
| 소비 | 네이버 언론사별 '많이 본 기사'에 이 사건 기사를 올린 언론사 수 | 35% |
| 발행 | 묶인 기사 수 | 25% |
| 검색 | 구글 트렌드·네이트·줌 실시간 검색어와 맞물리는가 | 25% |
| 급상승 | 처음 등장 후 3시간 안(서서히 식음)이거나 직전 수집보다 기사가 늘었는가 | 15% |

**키워드 점수** — 단어 단위 점수. `[weights]`

| 신호 | 뜻 | 기본 가중치 |
|---|---|---|
| 검색 | 구글 트렌드·네이트·줌 실시간 검색어에 올라 있는가 (순위와 트래픽 반영) | 35% |
| 발행 | 그 카테고리 기사 제목에 등장한 건수 (최근 24시간 말뭉치) | 30% |
| 소비 | 네이버 언론사별 '많이 본 기사' 제목에 등장한 건수 | 15% |
| 급상승 | 지난 7일 스냅샷당 평균 기사 수 대비 몇 배인가 | 20% |

가중치는 `config.toml`에서 바꿉니다(`config.toml.example` 참고). 순위에서 빼고 싶은 단어는 `data/stopwords.txt`에 한 줄씩 적으면 됩니다.

### 스토리는 어떻게 묶나

제목마다 변별력 있는 키워드(너무 흔하지도, 한 번만 나오지도 않는 말)를 뽑아 벡터로 만들고, 묶음의 중심과 비슷한 정도로 묶습니다(`newssignal/stories.py`). 중심과 비교하기 때문에 '경찰'처럼 여러 사건에 걸친 한 단어로 사건들이 줄줄이 이어 붙는 문제가 적습니다. 라벨은 묶음 안에서 30% 이상 공통으로 나온 말 2~3개, 대표 기사는 중심에 가깝고 많이 본 기사면 우선입니다. 직전 수집과 같은 기사 URL이 겹치면 같은 스토리로 이어져 변동·흐름 곡선이 유지됩니다.

### 이슈는 어떻게 접나

큰 사건은 국면마다 어휘가 달라(고성·눈물·해명·송구) 스토리가 여러 개로 쪼개지고, 그 국면들이 각자 순위를 차지해 화면을 덮습니다. 그래서 스토리 위에 **이슈** 단계를 둡니다.

1. 스토리마다 **앵커 후보**를 고릅니다. 그 스토리 기사의 절반 이상에 나오는 말(말뭉치의 25%를 넘게 덮는 말은 제외).
2. 같은 앵커를 가진 스토리들을 한 이슈로 묶습니다. 쌍으로 이으면 A-B, B-C → A-C 식으로 무관한 사건까지 엉키므로 '같은 앵커'라는 동치 관계로만 묶습니다.
3. **응집도 검사**: 앵커를 뺀 나머지 어휘의 평균 유사도가 기준보다 낮으면(트럼프의 LNG·연준·결혼식처럼 이름만 같이 나올 뿐이면) 그 앵커를 버리고 다른 앵커로 다시 시도합니다. 국면이 많을수록 쌍별 평균은 자연히 낮아지므로 기준도 같은 비율로 낮춥니다.
4. 앵커는 등장 비율의 합(무게)이 가장 큰 것을 고르고, 직전 수집에서 쓰던 앵커를 조금 우대합니다. 매 수집마다 묶였다 풀렸다 하면 순위 변동과 흐름 곡선이 끊기기 때문입니다.

이슈의 기사 수·언론사 수는 구성원 전체의 합집합이라, 큰 사건은 여전히 1위지만 한 줄만 씁니다. `NEWSSIGNAL_DEBUG_ISSUES=1`로 수집하면 앵커 후보와 응집도를 출력합니다.

### 넣지 못한 것과 이유

- **다음(Daum)**: 2025년 개편 이후 랭킹·연령별 인기 뉴스 페이지가 사라져(404) 가져올 데이터가 없습니다. 대신 네이트·줌 실시간 이슈어를 넣었습니다.
- **연령·성별 관심사**: 무료로 믿을 만한 출처가 없습니다. 네이버 데이터랩 API는 호출마다 최댓값을 100으로 놓는 상대값이라 연령대별로 따로 부른 결과를 서로 비교할 수 없고, 구글 트렌드는 인구통계를 주지 않습니다. 방송사 자체 홈페이지·앱 분석(GA4 등)이 유일하게 정확한 경로입니다.
- **신뢰도 주의**: 한글 형태소 분석기 없이 규칙으로 키워드를 뽑기 때문에 가끔 어미가 남거나 일반어가 올라옵니다. 급상승 신호가 쌓이면 상시 등장하는 일반어(AI, 대통령 등)는 자연히 내려갑니다. 눈에 띄는 단어는 `data/stopwords.txt`에 추가하세요.

## 파일 구조

```
newssignal/            수집·분석 패키지 (stdlib only)
```

## 바탕화면 런처

`~/Desktop/News Signal.app`(접시 안테나·전파 아이콘)을 더블클릭하면 이 맥의 로컬 대시보드(8770)를 엽니다. 서버가 꺼져 있으면 켜고 열고, 그래도 안 되면 공개 주소를 엽니다. 다시 만들려면 `bash scripts/build_launcher.sh`(아이콘 원본은 `assets/icon.html`).

## 다른 방법으로 보기

사내망에서 바로 보려면 `python3 -m newssignal serve --host 0.0.0.0`로 띄우고 `http://<이 맥의 IP>:8770/`로 접속합니다. `site/` 폴더는 정적 파일이라 어느 웹서버에 올려도 됩니다.
